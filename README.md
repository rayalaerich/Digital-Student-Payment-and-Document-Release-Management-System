# Digital-Student-Payment-and-Document-Release-Management-System

A web app for Partido State University – Goa Campus. Students register the ₱10 ID Validation Fee, the Cashier confirms the cash payment, and the Registrar releases the COE and the student sticker. It replaces the handwritten logbooks.

## Database

- Name: `psu_payment_release_db` (MySQL / InnoDB, 14 tables)
- `database/schema.sql`: tables, triggers and a view. Run it first.
- `database/seed.sql`: sample data. Run it second.
